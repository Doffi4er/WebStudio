# Адаптивні зображення (Retina 1x/2x × breakpoints)

Нова папка для **Завдання 1** — підготовка растрових зображень у форматах **1x та 2x**
для **мобільної, планшетної та десктопної** версій.

Оригінальні файли в `img/` **не змінені, не перейменовані й не видалені** — вони залишаються
у `src` кожного `<img>` як fallback для старих браузерів без підтримки `<picture>`/`srcset`.

## Схема імен файлів

`<група>-<номер>-<breakpoint>@<щільність>x.jpg`

- breakpoint: `mobile` (в'юпорт ≤ 767px) / `tablet` (768–1199px) / `desktop` (від 1200px)
- щільність: `1x` — стандартні екрани, `2x` — Retina (≈192dpi / 2dppx)

## Цільові ширини (за макетом WebStudio)

| Група       | мобільна | планшетна | десктопна |
|-------------|----------|-----------|-----------|
| work (Чим ми займаємося) | 450px | 354px | 370px |
| team (Наша команда)      | 450px | 354px | 270px |
| portfolio (Портфоліо)    | 450px | 354px | 370px |

Пропорції оригіналів збережено (без кропу), тому поточне десктопне відображення
не змінюється жодним пікселем.

## Підключення

- **Контентні зображення (`<img>`)** — через `<picture>` + `<source media="...">` з
  дескрипторами `1x`/`2x`, а для десктопа — `srcset` безпосередньо в `<img>`.
- **Фонові зображення (CSS)** — у проєкті наразі тільки CSS-градієнти (векторні),
  готовий шаблон з `min-resolution: 192dpi / 2dppx` додано коментарем у кінець
  `style.css` та `style_portfolio.css`.

## Структура

```
img/responsive/
├── work/        work-1..3-{mobile,tablet,desktop}@{1x,2x}.jpg
├── team/        team-1..4-{mobile,tablet,desktop}@{1x,2x}.jpg
└── portfolio/   portfolio-1..9-{mobile,tablet,desktop}@{1x,2x}.jpg
```

Всього згенеровано 96 файлів (16 джерел × 3 breakpoints × 2 щільності).
